# Reference UI storyboards

The patient and doctor storyboard images were supplied for this project and have been inspected for Phase 1. They are the visual source of truth for Phase 2 onward:

- Patient: blue primary colour, compact five-tab navigation, light blue cards and navy headings.
- Doctor: teal/green primary colour, equivalent compact navigation, white cards and navy headings.

The application will rebuild these interfaces with React Native components; it will not render the screenshots as in-app images.
